## 账号系统与部署

本项目的留言板使用邮箱 + 密码账号：注册需要邮箱 + 邮箱验证码 + 自设密码（至少 10 位），登录使用邮箱和密码；留言必须登录，不提供匿名留言。Worker 使用 D1 保存账号与留言。

部署前请确认 `wrangler.toml` 中的 D1 / KV 绑定与 Cloudflare 控制台一致，并确认 Worker Secrets（例如 `SESSION_SECRET`、`RESEND_API_KEY`）已设置。不要把密钥写入前端或提交到公开仓库。

静态前端部署到 GitHub Pages；Cloudflare Worker 负责 `/api/*` 与 `/auth/*`。前端和 Worker 都部署完成后，再分别测试注册、登录、退出、邮箱验证码注册、邮箱登录、账号留言和密码找回。
